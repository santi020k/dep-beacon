# Security Policy

## Supported versions

Security fixes are released for the latest published versions of Dep Beacon's editor extensions and npm packages. Upgrade to the newest release before reporting an issue that may already be fixed.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** option in the repository Security tab. This creates a private advisory and keeps sensitive details out of public issues, discussions, and pull requests.

Include the affected package or extension version, reproduction steps, impact, and any suggested mitigation. Do not include real credentials or data belonging to other people.

You can expect an acknowledgement within three business days and a progress update within seven business days. Please allow time for a coordinated fix and release before public disclosure.

For ordinary bugs and feature requests, use the public issue templates instead.
